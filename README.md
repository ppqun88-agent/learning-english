# Learning English

英语学习方案、内容制作流程与后续处理的统一仓库。

当前阶段：在首批 100 词试验与情景分类基础上，按用户授权逐阶段制作剩余词汇对话。实际完成度见分阶段统计；音频仍未开始。更新于 2026-10-22。

## 方向

围绕目标词汇组织自然的情景对话，将固定内容反复用于听力、理解和表达练习。场景数量由词汇关联与表达需要决定，不预设 100、500 或其他固定数量，也不规定每个场景必须包含多少目标词。

优先保证词汇覆盖、用法准确和对话自然。不为了满足重复次数而刻意把每个词安排到多个场景；自然出现的重复保留。

## 仓库分工

- [wordlists](https://github.com/ppqun88-agent/wordlists)：词汇原始资料和数据来源，保留来源历史。
- 本仓库：学习方案、内容规范、制作记录，以及后续经确认的文本、检查工具和处理流程。

最初仅建档；现已按后续授权开展分阶段文本生产。不复制整套第三方原始词库，不开发应用，不配置外部付费模型或音频服务。音频已有本地资源可用，后续再考虑。

## 使用边界

本仓库为公开仓库，不放个人测评答案、掌握程度、账号凭据或其他私人学习记录。学习材料覆盖某个词，不代表学习者已经掌握该词；词表的 CEFR 标签也不能直接作为个人能力评级。

后续工作先阅读上述文档，更新决策与处理记录后，再开展对应任务。提交采用独立任务分支；合并、部署和权限调整另行处理。
