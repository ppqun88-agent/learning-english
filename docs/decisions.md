# 目标、范围与决策记录

归档日期：2026-10-22。本文汇总英语学习讨论，不是已经实施的功能清单。

## 一、学习目标与背景

以实际理解和使用英语为目标，重视听力，兼顾词义、搭配和表达。此前讨论过新闻精听：英文内容、中文解释、关键词说明和回听；情景对话是当前进一步讨论的固定学习材料形式。两者可以并存，尚未决定替代关系或最终应用形态。

词汇库用于确定选材范围与检查覆盖，避免从零组织词汇；对话负责提供词语实际使用的上下文。

## 二、已明确的方向

1. 英语学习相关想法在本仓库建档，后续工作流与处理也以本仓库为入口。
2. 将有关联的词汇组织成自然情景对话，固定内容可反复学习。
3. 控制制作成本，不刻意追求每个词在不同场景反复出现；常用词自然重复不需要删除。
4. 讨论中的 100、500 个场景只是举例，不是数量目标。每个场景的目标词数、长度和拆分方式也未定。
5. 用户已有本地音频资源，音频后续再考虑；当前不选型、不配置、不生成音频。
6. 当前请求是归档方案与工作流，未要求立即批量制作全部课程、开发应用或调用付费模型。

## 三、建议，尚未确定为执行规格

- 先制作少量文本样稿，确认自然度、难度、解释方式和保存格式，再批量扩展。
- 先按词汇关联与使用任务分组，再确定情景数量；不按数字配额硬塞词。
- ChatGPT 可辅助讨论和起草，Codex 可结合仓库组织文件及检查覆盖；本地模型可在样稿标准稳定后比较。尚未指定生成模型、供应商、调用方式或预算。
- 采用独立的“词汇出现检查”和“语义审校”：自动检查出现了哪些词，人工或模型审校词性、义项、搭配是否正确。
- 可选择复述、接话、回忆与延后检查来验证学习效果；不强制增加新场景以实现这些练习。
- 逐词音频不作为当前前置条件；后续音频粒度可以按对话或句子讨论。

## 四、待定事项

- 目标词集的精确定义：讨论以约 5,000 词为方向，但尚未确定采用哪个来源集合、是否合并英美变体、是否按词形或词义计数。
- 对话的难度、英美用语偏好、人物数量、中文说明方式、长度及是否分节。
- 第一批样稿的范围和验收标准。
- 文本生成与审校工具、模型、执行环境和处理批次。
- 音频接口、声音、文件形式与本地处理流程，均留待后续。

## 五、历史建议的处理

此前建议过让同一词跨多个场景复现。考虑制作成本后，该建议不作为第一版要求。也曾以若干目标词、若干短对话说明试做方法，这些数字均不是固定生产规格。

## 六、更新方式

新决定应写明日期、决定内容和影响范围。讨论建议与已确认决定分开保存；只调整发生变化的部分。内容完成状态应以仓库中实际存在且经过检查的成果为准。
