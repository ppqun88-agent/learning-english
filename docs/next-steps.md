# 后续工作与接续规则

> 后续更新：本文件保留最初归档讨论；资源整合状态与当前可执行步骤见 [执行计划](execution-plan.md) 和 [整合说明](resource-integration.md)。文中“未复制/未实现”描述的是归档时点，不代表最新交付。

## 当前完成范围

- 归档学习方向和已明确的约束。
- 记录词库来源快照、计数口径与数据风险。
- 整理文本制作和覆盖检查流程。
- 将本仓库设为后续英语学习工作流与成果的统一入口。

尚无正式课程、目标词清单、生成程序或音频成果。

## 建议的下一步

1. 确认目标词集及计数规则，形成带来源版本的清单。
2. 按自然关联选取一个小范围，制作文本样稿。
3. 通过样稿确定难度、篇幅、解释形式、文件结构及审校标准。
4. 再组织批量文本制作和覆盖检查；模型与环境按届时条件确定。
5. 文本稳定后，再接入已有本地音频资源。

以上为建议顺序，不代表本次已启动全部工作，也未约定期限、场景数量或生成预算。

## 后续任务如何接续

- 先读 [README](../README.md)、[决策记录](decisions.md) 和 [工作流](content-workflow.md)，再检查仓库现有成果，避免重复生成。
- 新要求优先更新决策记录，注明已确认、建议或待定；不要将举例数字变成强制配额。
- 后续文本、模板、检查工具和处理记录留在本仓库；词库来源保留在原仓库并记录准确版本。
- 只提交实际完成的内容。验证记录应说明已检查、未检查和受阻部分。
- 使用独立任务分支提交并普通推送；不擅自强推、删除分支、合并或部署。
- 不写入私人测评、学习表现、凭据或本地环境秘密，不因本仓库公开而推定其他资料可以公开。

## 暂不开展

- 按固定场景总量分配课程。
- 为每个词强制生成多个不同场景。
- 全量逐词音频或音频服务配置。
- 新应用开发、部署或付费 API 调用。

这些事项若未来有新决定，再更新范围。
