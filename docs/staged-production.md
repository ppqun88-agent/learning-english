# 剩余词汇逐阶段生产

2026-10-22 用户已授权继续原分类框架，将剩余词汇分阶段完成分类、生成、独立审阅与验证；确实不宜自然匹配的项留到最后单列处理。本轮不生成音频，不开发或部署应用，不调用外部付费模型服务，不合并分支。

## 固定范围及计数单位

来源仍固定于 `3043da14627ed3c6168b598479bc110ce6b34736`：5,062 个索引词形、6,187 条来源词性/等级记录。原试验 100 个词形及其对话、义项和审阅原样保留。新生产范围为另外 4,962 个词形。每个词形选择至少一个明确的教学义项，不宣称覆盖全部词性或全部词义。其他来源记录保留为未选择/未审阅，不因为同一拼写已出现而升级状态。

## 阶段安排

12 个阶段，奇数阶段 413 项，偶数阶段 414 项。先按每个词形的最低来源 CEFR 排序，再以字母排序稳定划分审核工作量。这只是生产批次，不是主题分类，也不假定一篇对话全部为同一 CEFR。每阶段内部先按现实沟通任务分类，再起草；具体对话数、目标词数、长度和自然复现次数均不设配额。

剩余词形按最低来源等级：A1 899，A2 782，B1 691，B2 1,293，C1 1,297。阶段边界可以跨等级；实际义项可能选择同形词的另一来源记录，以明确、自然的用法为准。

每阶段依次：

1. 从不可变来源分配工作集，明确目标与候选词性。按既有主题或有理由的新主题，形成具体沟通任务；义项与场景对应须有语义理由。
2. 原创英文对话，记录目标来源 ID、选定词性、中文义项、准确证据句、作者与参与者。必要形态变化单独说明。
3. 另一名独立 AI 审阅者阅读完整对话和逐目标证据，检查自然度、连贯性、词性、义项、搭配及结尾。每个目标写具体理由，不以正则命中替代语义判断。
4. 起草者修订拒绝项，独立审阅者复审。审核绑定该版本文件字节的 SHA-256；改字后旧审核自动失效。
5. 形式检查和测试通过后，生成可读目录、逐阶段统计与校验清单，提交并普通推送到独立任务分支，核对远端提交后进入下一阶段。

审阅是有记录的独立模型判断，不是人工语言专家认证。程序验证身份、关联、证据、版本和状态，不能证明语言必然正确。未经审阅、被拒绝和暂缓的项不计覆盖。

## 许可与可重建性

完整来源清单、分批清单和详细暂缓台账仅在被忽略的 `build/` 中保存，不公开转载 Oxford 原始完整词表、PDF 或原文释义。公开的是原创教材的必要来源引用、选定义项、审阅与汇总统计。暂缓项不以原始词表形式发布；最终向用户提供带具体理由的独立处理清单。

```sh
python3 tools/pipeline.py import --source-dir ../wordlists-source
python3 tools/prepare_staged_inventory.py
python3 tools/staged_corpus.py --write
python3 tools/staged_corpus.py --require-phase phase-01
python3 -m unittest discover -s tests -v
python3 tools/check_pilot.py --targets build/targets.jsonl
python3 tools/classify_pilot.py
```

逐阶段完成与整体完成严格分开。一个阶段全部处置可包含暂缓项；“已处置”不是“已接受覆盖”。报告始终保留原始分母，不通过排除疑难词提高覆盖率。最终剩余项须具体说明不能完成自然用法的原因及后续建议，而不是用“难”统一代替分析。

最新实际结果见 [分阶段教材与统计](../corpus/staged-v1/README.md)。此计划本身不代表任何新增词形已经完成。
