## 已核验的统计口径

从该版本 `categories.json` 读取，排除 `_meta`：

- 全部英文索引键：7,009 个。
- 标签包含 `Oxford3000` 或 `Oxford5000` 的索引键并集：5,062 个。

这些数字按索引键计数，不是词族数量、义项数量，也不是学习者已掌握词汇量。Oxford 集合包含英美拼写等整理差异，因此不能把“Oxford 5000”名称直接理解为当前文件恰有 5,000 个唯一键。

来源 README 的释义段仍写 7,008，而类别索引实际为 7,009。后续统计应固定版本、明确字段和去重方式，不能仅抄 README 数字。

当前尚未导入或确定本项目的最终目标清单。不要从 5,062 个键中任意删到 5,000，也不要将整个 7,009 词并集自动作为本项目目标。

## 数据使用注意事项

- 类别不是互斥集合，同一个词可能属于多个词表和多个 CEFR 标签。
- `categories.json` 的聚合标签不能完整表示词性和义项关系。例如同形词在不同用法下可能对应不同等级，需要回查原始表。
- 释义包含未清洗的专业领域内容、说明行和可能不合适的匹配，不能直接全部灌入学习材料。
- 单个音标字段未必充分区分同形异音、词性重音及英美发音；音频制作前还需核对。
- 英美拼写、大小写、屈折变化和多词表达需要明确规则，不能简单全部小写后视为同一教学项目。
- 本来源提供词表与释义，不直接提供本项目的情景课程或学习记录。

## 覆盖应如何定义

建议保留原始拼写、来源版本与来源标签，并为项目目标建立稳定 ID。为每个目标明确当前使用的词性和义项。

覆盖至少分成两层：

1. 形式覆盖：词形或认可的变化形式是否出现在指定句子。
2. 有效用法覆盖：该处词性、义项和搭配是否符合目标。

一个词出现一次，不能自动记为它的全部义项已覆盖。更不能将内容覆盖状态写成个人掌握状态。
